# med-alarm

약국 복약 알림 QR용 정적 페이지 (GitHub Pages).

QR 주소 예: `https://dongjoonmin.github.io/med-alarm/?t=1900&i=3&n=10&l=저녁`

| 값 | 뜻 |
|---|---|
| `t` | 알림 시각 HHMM (여러 개는 쉼표) |
| `i` | 간격(일), 기본 1 |
| `n` | 횟수 |
| `s` | 시작일 YYYYMMDD, 기본 오늘 |
| `l` | 표시 이름(선택, 한글·영문·숫자만) |

개인정보를 받거나 저장·전송하지 않습니다. 일정 파일(.ics)은 접속한 폰 안에서만 만들어집니다.
